# Thomas Malacchina — CV dynamique

CV interactif en ligne : voyage visuel de l'espace au noyau de la Terre, en passant par le ciel, la skyline urbaine et les racines souterraines.

## Stack

- **Next.js** (App Router, Turbopack)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**

## Lancer en local

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).
